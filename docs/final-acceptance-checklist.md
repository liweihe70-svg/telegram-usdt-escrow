## 私聊双方流程

每项新建独立普通订单，避免把演练订单当作双账号验收。资金操作前核对页面上的入金方和完整编号。

| 待验项目 | 操作与通过标准 |
| --- | --- |
| 商品完成（A买B卖） | 双方确认同一条款；仅管理员注入模拟入金；B声明交付，A二次确认放款；双方显示完成，本金给卖家、费用给平台。 |
| USDT买卖（A买B卖） | 卖家为模拟入金方；A声明法币付款，B二次确认放币；本金给买家、费用给平台；不支付真实法币。 |
| 角色反向 | B创建订单、A为对方；互换角色再跑一次商品或P2P，核对操作者权限和邀请。 |
| 未授权角色操作 | 买家不能声明商品交付，卖家不能代买家验收；P2P反向权限同样受限，失败后资金与状态不变。 |
| 退款同意 | 一方申请、另一方同意并确认；本金及费用回入金方，只有一套模拟退款记录。 |
| 退款拒绝 | 一方申请、另一方拒绝；回原阶段且不产生出款。 |
| 争议及双方证据 | 两方都提交文字及各一份附件，双方和管理员可查看；普通资金操作暂停。 |
| 人工仲裁 | 管理员分配金额总和等于可分配金额，确认后双方收款记录正确；普通账号不能裁决。 |
| 重复/旧按钮 | 结算后再点旧确认，状态、出款标识和账本不重复；过期草稿/状态按钮给出可理解提示。 |
| 中英文通知 | A收到中文、B收到英文；交易约定和证据原文不被改写。 |

- [ ] 上表逐项记录结果；每笔结束后在面板核对状态、出款记录与账本，不只看聊天提示。
