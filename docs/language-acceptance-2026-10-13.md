# 中英文语言验收

2026-10-13，Asia/Shanghai。

## 已实现

首页语言按钮与 `/language` 选择器，`/language en`、`/language zh`；中文为默认值。语言偏好在 `bot_languages` 按用户持久保存，选择语言不清空向导。

菜单、向导、状态、订单、说明、查询、通知、模拟演练、争议与仲裁中的系统文本使用本地英文资源。英文命令菜单按Telegram默认英文客户端和用户选择分别注册。命令与按钮回调编号保持不变。

翻译仅作用于代码中的系统文本片段。金额、订单编号、地址、品牌配置和用户填写的约定/证据/裁决理由原样插入，不进行整条消息替换。异步语言上下文按请求隔离，后台通知分别读取收件人偏好。
