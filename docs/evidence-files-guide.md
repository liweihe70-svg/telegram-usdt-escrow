# 图片与文件争议证据

订单进入争议状态后，买家或卖家与自己的机器人私聊，发送图片或文件，在该附件的说明（caption）中填写：

```
/file_evidence 完整订单编号 证据说明
```

说明可省略，最多1000字（Telegram 自身也限制 caption 长度）。每次单独发送一个附件并填写说明；不接收没有订单编号的附件，也不接收群文件。无需第二账号即可在单账号演练的争议订单上由本人提交。

支持 JPG、PNG、PDF、UTF-8 TXT；按扩展名和文件签名或文本编码校验，并非恶意内容检测。单份最多5MB，每位参与方每单最多5份，每单合计20MB，本地全部附件合计50MB。暂不支持 ZIP、可执行文件、HTML、SVG、视频。

双方及已配置管理员使用 `/evidences 订单编号` 分页查询文字与附件，点击下载按钮取回。其他用户无权获取。仲裁开始后不能追加，已有记录继续保留。机器人更新重放不会重复存储文件；下载期间状态变化会再次校验。

控制面板打开争议订单，争议记录中可预览 JPG/PNG、下载全部支持的附件。PDF/TXT 只提供下载。下载要求有效本地控制会话与来源，返回 attachment 和 nosniff 头；不会公开 Telegram 下载链接。文件名清理路径与控制字符，证据说明保持用户原文，按钮支持中英文。

附件二进制、大小、SHA-256、提交人、说明与时间保存在 PGlite 数据库中；现有加密备份及全表恢复校验包含附件。旧备份不会包含备份创建之后的附件。无需再次提供已有恢复密码给聊天。
