# 担保机器人完整操作指南（主网 · 真实 USDT）

适用于当前版本：主网后台 **http://127.0.0.1:8784**，BNB Chain（56），只收官方 BEP20 USDT（合约 `0x55d398326f99059fF775485246999027B3197955`），资金转出全自动。

> **铁律**：遇到本指南没写到的情况，先点「关闭自动出款」，截图记录，不要重复转账，不要重新签名。

## 二、每次开机 / 重启后要做的事（5 分钟）

1. 双击 **`启动主网后台.cmd`**。它会先编译再启动，然后自动打开浏览器。（若设置了开机自启动，可跳过这步，直接打开 http://127.0.0.1:8784）
2. 登录后台。页面顶部红色横幅表示真实资金，正常。
3. 进入 **「网络配置」**：
   - 确认 **入金监听** 在运行（没运行就点启动，输入 `MAINNET`）。
   - 确认 **Telegram 机器人** 在运行（没运行就点启动）。
   - 一般会自动恢复上次的运行状态，只需检查。
4. 页面最上方 **「🤖 自动出款」**：
   - 选择 **平台钱包加密备份文件** → 输入 **备份密码** → 点 **「解锁钱包」**。
   - 「钱包」显示 **已解锁**。
   - 如果「状态」显示 **已关闭**，点 **「开启自动出款」**，输入 `AUTO`。
5. 完成。之后放款、退款都会自动处理。

> 为什么每次都要解锁？私钥只放在内存里，不写硬盘，这样即使电脑硬盘被拷走，钱也拿不走。没解锁期间机器人会私聊提醒你，出款会排队等待，不会丢。

**电脑要求**：保持开机、不睡眠（Windows 设置 → 电源 → 睡眠改为“从不”）。电脑关机期间不处理入金和超时，开机后会补扫。

## 三、用户是怎么交易的（你需要能给别人讲清楚）

用户在机器人里点 **INSTRUCTIONS / 使用说明** 有给用户的傻瓜版说明。完整流程：

1. **建群**：任一方私聊机器人 → 点 **CREATE ESCROW GROUP / 创建担保群** → Telegram 让你选或新建一个群，机器人以管理员身份进群（保留默认权限）。机器人会发一个邀请链接，发给对方，对方申请入群后自动通过。
2. **设角色**：卖家发 `/seller 钱包地址`，买家发 `/buyer 钱包地址`（BEP20，0x 开头）。也可以直接把地址贴到群里：第一个人点按钮选角色，第二个人贴地址会**自动**成为另一方。
3. **自动生成订单**：双方地址都有了，机器人立即发出「📍 交易信息」卡片，几秒后显示本单**托管地址**。**不需要填金额。**（想记录交易内容，可在第二个人设角色前发 `/terms 内容`。）
4. **入金**：买家先发 `/verify 托管地址` 核对，再把双方约定的金额转入（BNB Chain 上的 USDT，不能转错链）。到账后机器人**自动在群里显示余额**（托管余额、卖家可得、手续费），也可以随时发 `/balance` 查看。
   - 少转了：再转差额到同一地址，余额累加（买家点放款前都可以补）。
   - 金额必须大于最低手续费，订单才会开始。
5. **交付**：卖家先发 `/balance` 确认到账金额够约定的数，再交货，然后点 **已交付**。
6. **放款**：买家确认收到货后点 **放款给卖家** 并再次确认 → 系统**自动**把「托管余额 − 手续费」转给卖家 → 群里通知完成。买家申请放款后再转入的钱会转人工处理。
7. **退款**：
   - 卖家点 **退款给买家** → 直接全额退给买家。
   - 买家点退款 → 需要卖家同意；卖家拒绝就转为争议。
   - 入金后 24 小时卖家没点「已交付」→ **自动全额退款**给买家。
8. **争议**：任一方点 **争议** 或发 `/dispute 理由` → 资金冻结，等仲裁员裁决（见第五节）。

群内常用命令：`/menu` 菜单，`/balance` 余额，`/blockchain` 链上记录，`/qr` 收款二维码，`/verify 地址` 核对地址，`/reset` 重置，`/language en` / `/language zh` 切换群语言。

## 四、日常要看什么（每天 5 分钟）

1. **Telegram 提醒**：机器人会私聊你，重点看这几种：
   - 🤖 **自动出款已广播**：正常，可到 BscScan 用交易哈希核对。
   - 🔒 **钱包尚未解锁**：后台重启过，按第二节第 4 步解锁。
   - ⛔ **自动出款连续出错，已自动暂停**：见第七节。
   - **新争议**：去处理（第五节）。
   - **人工待处理**：去处理（第六节）。
   - **手续费钱包余额不足**：往手续费钱包转一点 BNB（0.01 BNB 够几千笔）。
2. **后台「概览」**：看进行中订单、托管总额是否正常。
3. **「自动出款」面板**：「状态」已开启、「钱包」已解锁、「入金监听」运行中；若有「最近错误」看一眼内容。

提醒接收人在「网络配置 → 管理员 Telegram 提醒」里设置（填你的 Telegram 数字 ID，该账号先私聊机器人 `/start`，点“发送测试提醒”确认能收到）。

## 五、处理争议（仲裁）

1. 后台 **「退款与争议」** → 打开该案件。
2. 看双方理由、聊天说明、上传的附件（截图等）。需要更多信息可以在群里问双方。
3. 选择裁决结果：**全部给卖家** 或 **全部退买家**（目前不支持按比例分配），填写理由，确认。
4. 裁决后系统**自动出款**，群里会通知双方。

**让别人当仲裁员**：「网络配置」→ **账号管理** → 账号名、角色选 **仲裁员**、初始密码（12 位以上）→ 添加账号。把后台地址和账号给他（他需要能访问你这台电脑的 8784 端口，通常就是在这台电脑上操作）。仲裁员只能看和裁决争议，碰不到钱包和设置。不用时点 **停用**。

## 六、人工待处理订单

多付、关单后才到账、到期没补足、链上确认冲突等会进入“人工待处理”。打开订单详情，底部“人工处理”：

| 选择 | 什么时候用 | 确认词 |
| --- | --- | --- |
| 确认入金并继续交易 | 地址里的钱合计**正好**等于应付金额 | `CONTINUE` |
| 全部退回买家 | 地址里有钱，要退 | `REFUND`（之后自动出款） |
| 关闭订单 | 地址里没有钱 | `CLOSE` |

每次都要写处理说明，记录不可修改。

## 七、出问题了怎么办

| 情况 | 怎么做 |
| --- | --- |
| 自动出款被暂停 | 「自动出款」面板看「自动暂停原因」。常见：RPC 节点不通（换备用 RPC `https://bsc.drpc.org`）、手续费钱包没 BNB（充值）。处理后点「开启自动出款」输入 `AUTO`。 |
| 想立刻停止一切转出 | 点 **「关闭自动出款」**，更保险再点 **「锁定钱包」**。 |
| 出款很久没到账 | 系统 10 分钟自动加速一次。在 BscScan 查交易哈希；仍有疑问先关闭自动出款，截图找技术支持。 |
| 机器人不回复 | 「网络配置」看机器人是否运行，重新启动；仍不行重启后台（第八节）。 |
| 用户转错链 / 转错币 | 系统无法自动识别，不会入账。需要人工核对后从链上手动处理，先不要承诺。 |
| 忘记后台密码 | 没有找回功能，联系技术支持。 |
| 弄丢钱包备份或密码 | **资金可能永久无法取出**。务必现在就检查备份是否存了两份。 |

## 八、重启 / 停止后台

- **停止**：后台右上角 **「停止后台」**，输入 `STOP`。
- **启动**：双击 **`启动主网后台.cmd`**。
- 重启后：检查入金监听和机器人在运行，**重新解锁钱包**（第二节第 4 步）。
- **开机自启动**：双击 `设置开机自启动.cmd`；取消用 `取消开机自启动.cmd`。自启动后仍需要你手动解锁钱包。

## 十、安全守则

1. 钱包备份文件存**至少两份**（U 盘 + 另一块硬盘），密码分开保存。
2. 后台电脑只做这件事：不装来路不明的软件，不点陌生链接，开系统自带杀毒。**钱包解锁期间，电脑被入侵 = 钱可能被转走**（当前没有设置金额上限）。
3. 离开较长时间、或发现电脑异常：先「关闭自动出款」+「锁定钱包」。
4. 后台只在本机访问（127.0.0.1），不要做端口转发暴露到公网。
5. 每周做一次「加密备份与恢复校验」。
6. 任何自称客服、管理员找你要密码、备份、Token 的，都是骗子。

## 十一、固定托管地址模式（人工出款）

在后台「网络配置 → 🏦 固定托管地址」填你自己的钱包地址后，**新的**群订单都显示这个地址作为托管地址。平台没有这个地址的私钥，所以：

- **入金识别**：买家必须用他在 `/buyer` 里填的地址付款，系统会自动记到对应订单。从交易所提币的，到账后由买家在群里发 `/paid 交易哈希` 认领，你在后台点「记入订单」确认。
- **同一个买家地址**同一时间只能有一笔进行中的订单。
- **出款**：买家放款、退款、仲裁或超时退款时，机器人私聊提醒「💸 需要你手动转账」。你从固定地址**一次性**转出**准确金额**到提醒里的收款地址，系统看到后自动完成订单并通知群里。金额或地址不一致的转出会显示为「未匹配的转出」，不会完成订单。
- **手续费**直接留在你的地址里。
- **无法识别的入金**（例如你自己的私人转账）显示在后台，可以「记入订单」或「忽略」。
- 入金监听必须运行，系统才能看到入金和你的转出。这个模式不需要平台钱包，也不需要解锁钱包或开启自动出款。
- 还有使用固定地址的订单没结束时，不能更换或清除固定地址。
