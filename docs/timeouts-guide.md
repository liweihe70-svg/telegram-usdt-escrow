# 订单超时与自动提醒

控制面板进入「机器人配置」，下方「订单超时与自动提醒」可修改各阶段时限和提醒间隔，范围均为5至10080分钟，支持中文和英文。

| 阶段 | 默认时限 | 到期处理 |
| --- | --- | --- |
| 待双方确认 | 60分钟 | 没有入金则关闭 |
| 待入金 | 30分钟 | 没有入金则关闭 |
| 已入金、待交付 | 1440分钟 | 保留资金，暂停普通操作，转人工 |
| 待验收或确认法币收款 | 1440分钟 | 保留资金，暂停普通操作，转人工 |
| 退款协商 | 1440分钟 | 保留资金，暂停普通操作，转人工 |
| 争议 | 1440分钟 | 标记超时并提醒管理员，继续允许人工仲裁 |

默认提醒间隔60分钟。提醒间隔短于该阶段时限时，期间可收到阶段提醒。进入争议后，定时提醒发给管理员。超时转人工时双方和管理员收到状态提示；之后定时提醒管理员。

如果订单已经有少付、多付等异常入金，自动任务保留订单供人工处理，不把已收到的款项当作「未入金」。未入金订单到期后迟到款项归异常账本，不能重新激活订单，包括定时检查尚未执行的空档。

## 人工处理

「机器人配置」下方显示最多20笔超时待处理订单。打开订单可查看截止时间、超时提示和「恢复普通处理」按钮。确认后以原阶段时限重新计时，不放款、不退款、不改变订单金额，操作会留下管理员记录。旧的恢复按钮若记录版本变化会被拒绝。

Telegram 已配置管理员可进入 `/admin` →「超时待处理」→ 选择订单 → 确认恢复。交易方不能冒充管理员恢复。已入金订单超时期间，双方仍能发起争议；争议中的证据与人工仲裁继续可用。普通交付、放款和退款操作在恢复前暂停。

## 配置与运行

- 每次进入新阶段，数据库保存该阶段截止时间和提醒间隔。修改时限只影响新订单和后续阶段；管理员恢复仍使用该阶段原来保存的时限。
- 升级前旧订单不追溯计时，在下一次阶段变化后开始。该阶段未启用计时会在详情显示。
- 关闭「自动检查超时」暂停自动任务，不清除截止时间、队列或已有人工处理标记。重新开启后按原截止时间补检。关闭期间进入新阶段的订单暂不设截止时间。
- 面板服务每30秒检查一次，即使机器人停止也检查超时。电脑睡眠或服务停止期间无法执行；启动后补检。
- Telegram 通知只在机器人运行时发送。管理员及双方须先私聊机器人建立联系方式；未建立联系者需要通过订单或面板查看状态。
- 提醒事件、阶段版本、通知收据、失败重试时间均保存到数据库，并随加密备份保存。离线恢复时不会逐轮补发历史提醒，阶段已经变化的旧提醒会跳过。
- 私聊通知失败从30秒开始延迟重试，逐步增加到最多1小时。已记录成功的收件人不重复发送；若进程在 Telegram 接受消息后、保存收据前崩溃，仍可能重复一条消息，不能承诺严格只发一次。
- 超时任务不创建任何结算或出款。已有明确授权进入结算的订单继续走原来的模拟结算流程。
