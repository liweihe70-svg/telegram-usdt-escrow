# 本地测试部署助手

访问 http://127.0.0.1:8783/ 。使用安装MetaMask的Edge/Chrome；Codex内置浏览器没有该钱包扩展。根目录“启动测试部署助手.cmd”可再次启动服务并用默认浏览器打开。现有8782正式后台保持原样。

## 使用

1. 在MetaMask选择BNB测试网（97），打开助手，点击“连接钱包”，由你在扩展中批准连接。钱包锁定时自行解锁，不向页面或聊天填写密码、私钥或助记词。
2. 检查部署账号是否是已收到测试币的账号，余额是否足够；页面只支持测试网97，不自动添加或切换网络。
3. 点击“估算部署手续费”。页面展示账号和手续费预算，含20% gas余量；估算有效期两分钟。最终钱包显示为准，账户/网络变化需重新估算。
4. 核对TESTUSD、18位精度、100万枚供应，输入TESTNET，点击“部署，并在钱包中确认”。交易是Value为0的测试合约创建，消耗tBNB手续费。由你在MetaMask审阅并批准或取消。
5. 交易提交后页面记录哈希并查询回执；核对链、部署人、创建交易、金额0、部署字节码、成功且规范链上的回执、合约代码和代币属性。成功显示合约地址和当前部署账号的TESTUSD余额，可复制地址，再选择在钱包中添加代币。
6. 部署结果截图或公开合约地址可以分享。随后在8782“网络配置”填入此测试合约；正式收款分支及RPC仍需配置，部署不自动改写正式数据库。

助手有中英文选项。不提供任何私钥字段、助记词字段、服务端签名、主网部署、真实USDT支付或资金托管功能。浏览器只通过已连接钱包进行签名请求；页面的脚本/依赖/合约文件均由本机服务提供，无远程CDN。

## 中断恢复

提交前先写入本浏览器本地记录，取得哈希后立即保存。等待回执期间刷新页面不会自动重新发起部署。重新连接钱包后可查询原交易，也可在“已有部署交易”中粘贴完整交易哈希核验。

钱包可能已广播但页面未收到哈希：记录保持“结果不确定”，阻止再次部署。请从MetaMask活动记录复制交易哈希核验，不要清除网站存储来绕过此保护。已成功的记录会阻止重复部署；本助手面向一次性测试合约初始化。

同一网站的多个标签页通过Web Locks互斥；不支持Web Locks的浏览器不允许发起部署。不同浏览器、不同浏览器配置或localhost与127.0.0.1是不同存储来源，不能实现跨来源互斥，因此请只使用一个浏览器并固定本页127.0.0.1网址。

用户明确取消后允许重新估算；如果回执核验确认原交易已失败，通过同一哈希的手动恢复查询将记录标为失败，随后才允许重试。查询失败或长时间没回执并不代表交易失败，不能据此重新部署。

当前页面核验的是已入块成功回执，不称为最终确认。后续正式入金监听另行执行finalized验证。
