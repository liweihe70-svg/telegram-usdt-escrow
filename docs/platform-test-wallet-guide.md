# 平台测试收款钱包初始化

本机助手 http://127.0.0.1:8783/#platform-panel 的第4部分用于初始化平台专用测试收款分支，与部署TESTUSD的MetaMask账号分开。无需连接MetaMask，不消耗tBNB，也不发送交易。

1. 刷新助手页面，滚动到“初始化平台测试收款钱包”。
2. 两次输入自行保管的加密密码（12–128字符），点击生成。不要将密码发到聊天。
3. 等待本机加密完成，点击“下载加密钱包备份”，保存JSON文件。浏览器还保存一份加密副本，以便刷新后重新下载；它不是外部备份，不能依赖清理缓存后的浏览器恢复钱包。
4. 在“验证备份后再配置后台”选择刚下载的JSON文件，输入同一个密码，点击验证。浏览器本机解密核验公开分支，没有文件上传；核验通过才启用复制xpub按钮。
5. 点击“复制已验证的公开xpub”，稍后将其粘贴到8782“测试网收款与入金监听”的公开分支字段。不要把钱包地址、私钥、助记词或整个备份JSON填入该字段。
6. 此时RPC尚未准备好，不必点击正式后台的保存/启动。准备好RPC后再一起保存。根首次保存后不能替换、不能倒退地址序号，请保留此备份。

生成层级固定为 `m/44'/60'/0'/0`。每单地址是该分支的非硬化子地址0、1、2……；页面的第一个地址只是预览，不是已创建订单的收款通知，请先不要转账。

备份为ethers JSON Keystore：scrypt N=131072、r=8、p=1，AES-128-CTR，保存加密的私钥与加密恢复熵、派生路径和公开xpub元数据。私钥和恢复资料在生成/解密期间存在于浏览器内存中，JavaScript不能保证安全清零；页面不显示这些明文，不在localStorage保存明文，不发送给本机HTTP服务或第三方。别在不可信的页面/浏览器扩展环境中使用此工具保存主网资金密钥。本工具仅用于本项目测试钱包初始化。

备份含测试网标记，但标准EVM密钥本身不受链限制，此标记不能技术上阻止其他软件用于主网。主服务只导入公开xpub，独立签名服务仍待实现；不要误认为生成备份就具备放款能力。

恢复验证会检查格式、KDF上限、测试链标记、完整路径、解密后的HD节点和公开分支一致性。格式/密码错误或不同根备份不会替换本浏览器现有根。已有备份时生成入口隐藏，避免误操作；多个同源标签页使用Web Locks避免同时生成。不同浏览器/网址来源不能共享此互斥，固定使用127.0.0.1并保留原文件。

复制的xpub是公开信息，但会暴露派生地址。备份文件和密码必须自行保管，不上传到聊天。不能从公开xpub还原私钥。

开发验证使用公开合成测试助记词，覆盖实际加密/解密、恢复子地址签名密钥一致、输出不包含明文秘密、错误密码与错链/篡改公开根/KDF超限拒绝。没有读取用户钱包、生成用户秘密或实际签名交易。新页面的浏览器点击与用户实际备份验证仍需完成。
