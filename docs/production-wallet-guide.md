# 测试网收款地址与入金监听

此模块已实现每单地址、最终确认扫描与账本入金，但只允许 BNB 测试网（97）的指定18位测试代币。主网实际资金和放款广播仍关闭。不要向测试地址发送主网 USDT。

更新：测试网商品RELEASE已接入独立签名和明确广播，见 [出款指南](production-payout-guide.md)。下文“签名/广播尚未接入”为历史阶段限制；主网、退款、仲裁、gas补给与手续费归集仍未启用。真实双账号全流程尚待联调。

## 本机操作

1. 更新后台：在8782右上角“停止后台”，输入 STOP。然后双击“启动正式后台.cmd”，刷新页面并登录。停止会等待监听任务退出，保留管理员、订单、账本、地址序号及扫描进度。
2. 打开“网络配置”，选择 BNB 测试网（97），填写实际部署的18位测试代币合约。不要直接把主网 USDT 合约当作测试网代币。
3. 在“测试网收款与入金监听”填测试钱包的**外部收款分支公开 xpub**，约定层级为 `m/44'/60'/0'/0`。主服务只做此公开分支的非硬化子地址派生，无法签名。请保管对应的测试钱包与完整路径，后续签名服务必须核对两者一致。
4. 只在本机填 BNB 测试网 HTTP/HTTPS RPC 地址，保存配置。RPC 如带 API key 不要发到聊天；页面不会回显。凭据存于忽略提交的 `.env.production`，配置文件应只允许本机负责人访问。公开 xpub 存于正式数据库，不能用它恢复私钥。
5. 点击“启动测试网监听”，输入 TESTNET。启动会核验链ID、合约代码、18位精度、最终确认区块及日志接口；失败则保留进度并停止，不自动反复启动。
6. 在正式后台创建商品订单，将邀请链接分别发给真实买卖双方。两人通过自己的 Telegram 私聊确认条款和本人钱包后，监听器为订单分配地址，通知双方。买家刷新订单，在监听开启时查看独立测试收款地址。
7. 买家用测试钱包向该地址**一次发送完整应入金额**（本金加手续费）。监听仅在最终确认后验证真实回执和 Transfer 事件，再记入复式账本，订单变为“已入金”。卖家声明交付、买家二次验收申请后进入管理员审核。通过审核仍为“待签名”，本阶段不会出款。
8. 点击“刷新”查看最近扫描时间、地址数量、订单入金和审计记录。监听每10秒启动一次新扫描，单地址每次最多1000区块；积压较大时分批追赶。停止后台或监听后，旧 Telegram 消息无法撤回，不要继续转账，重新查看订单状态。

只有一个账号时仍可配置后台、公开分支与节点，并查看自己的确认流程；生产流程不允许同一账号充当双方。真实双账号确认和测试代币转账需要最终联调，不能用后台伪造另一方身份或注资。

## 持久化与异常规则

- 第一版一个数据库只接受一个测试收款根及一种指定测试代币。首次导入后锁定，不能替换、删除或倒退地址序号；修改 RPC 时重新输入同一 xpub 与新的 RPC。不要通过删除数据来“修复”已使用的地址。正式资金版的安全换根/资产迁移另行实现。
- 配置保存不会自动启动监听。后台重启后需人工再次启动；扫描接着数据库中的进度处理，不重新分配已绑定地址。独立地址及根序号有数据库唯一约束。
- 新地址从分配时最终确认高度之前两块开始扫描，不作为历史钱包导入器。必须使用专用于本系统、此前未收款的测试分支。
- 每个链事件以链ID、交易哈希和事件序号唯一识别；中断后重扫不会重复记账。扫描进度只有在整段回执处理成功并重新核对区块哈希后才推进。
- 回执缺失、链或金额核验失败、RPC 请求失败时不跳过范围。少付、多付、额外入金或非待入金状态的转入登记为异常款，保留账本并转人工处理，暂停待审核/已审核出款；此版不合并多笔少额转账自动凑款。
- 已分配地址继续监听，包括已入金及后续状态。启动时或扫描中发现已最终确认区块哈希变化，将已分配地址对应订单转人工处理并阻止未完成出款。不会自动删除或回滚账本；需要核查节点和账本后制定恢复方案。
- 如果 RPC 最终确认高度回退，监听暂停；如果根或 RPC 保存失败，先刷新状态再重试。公开根可能已保存，重试必须仍使用同一个根。
- 每单地址持有测试代币不等于可以转出：需要独立签名服务、该地址的 BNB gas、审批绑定、nonce 和回执处理。当前尚无归集、退款或签名广播能力。

## 配置来源

面板运行时的链和代币以正式数据库的“网络配置”为准；公开根保存在数据库；RPC 保存为 `.env.production` 的 `BNB_RPC_URL`，供重启时读取。命令行 `production:preflight` 仍读取独立环境字段 `BNB_CHAIN_ID` / `BNB_TOKEN_CONTRACT`，如使用该命令需在本机保持它们与面板一致。不要在日志、截图或聊天中公开配置文件。

XPUB 可以看到账户地址，不提供签名能力，也不能证明完整派生路径或资金控制权。实现依据：[ethers HDNodeVoidWallet](https://docs.ethers.org/v6/api/wallet/#HDNodeVoidWallet)、[BNB 最终确认接口](https://docs.bnbchain.org/bnb-smart-chain/developers/json_rpc/bsc-api-list/)。
