# 主网（真实 USDT）实例启用指南

主网实例与测试网实例完全分开：独立端口 **8784**、独立数据库 `data/production-mainnet`、独立配置 `.env.mainnet`、独立备份目录、**独立的 Telegram 机器人**和**独立的平台钱包**。测试网实例（8782）照常保留，用于复现问题。

## 默认安全限制

| 项目 | 默认 | 配置项（`.env.mainnet`） |
| --- | --- | --- |
| 单笔本金上限 | 20 USDT | `PRODUCTION_MAX_ORDER_USDT` |
| 进行中订单托管总额上限 | 100 USDT | `PRODUCTION_MAX_CUSTODY_USDT` |
| 手续费 | 1%，最低 1 USDT | `PRODUCTION_FEE_BPS`、`PRODUCTION_FEE_MIN_USDT` |

- 只接受 BNB Chain（56）官方 BEP20 USDT 合约 `0x55d398326f99059fF775485246999027B3197955`，其他代币不会入账。
- 订单只能由管理员在后台创建，相当于白名单。
- 出款、补 gas、归集、加速都需要你审核、在本机浏览器签名，并输入 **MAINNET** 才会广播。私钥不在服务器上。
- 修改限制后需重启主网后台。

## 首次启用步骤

1. **配置文件**：在项目目录执行（不会覆盖已有文件）：
   ```powershell
   if (-not (Test-Path .env.mainnet)) { Copy-Item .env.mainnet.example .env.mainnet }
   ```
   Token 和 RPC 也可以之后在后台页面填写，无需手动编辑。
2. **启动**：双击 `启动主网后台.cmd`，打开 http://127.0.0.1:8784/ ，设置**新的**主网管理员账号和密码（与测试网分开）。页面顶部红色横幅表示主网真实资金。
3. **网络配置**：选择 BNB 主网（56），代币合约填 `0x55d398326f99059fF775485246999027B3197955`。
4. **主网平台钱包**：重新启动 `启动测试部署助手.cmd`（加载新的端口许可），打开 http://127.0.0.1:8783/ ，右上角切换为“BNB 主网 56 · 真实资金”。在第4部分生成**新的**平台钱包，下载加密备份并完成验证，复制 xpub。测试网钱包备份不能用于主网签名。
   - **这份钱包备份和密码就是所有托管资金的钥匙**：复制到 U 盘或另一块硬盘，与密码分开保存。
5. **入金监听**：在 8784 “网络配置”粘贴 xpub，RPC 填 `https://bsc-rpc.publicnode.com`（备用 `https://bsc.drpc.org`），保存后启动监听并输入 MAINNET。
6. **手续费钱包**：签名页面（主网模式）第5部分连接 8784 后显示手续费钱包地址，从自己的钱包转入约 0.01 BNB（按当前 gas 价格可支付数千笔）。
7. **机器人**：在 BotFather 新建机器人，把 Token 填入 8784 后台并启动。不要使用测试网机器人的 Token。
8. **备份**：在 8784 “网络配置”底部创建一次加密备份并校验恢复。

## 第一笔真实交易（建议 ≤10 USDT）

1. 后台创建订单：买家=朋友的 Telegram 数字 ID 与钱包地址，卖家=你的 ID 与钱包地址，本金 10。把邀请链接发给双方。
2. 双方在私聊确认条款和本人钱包地址；系统分配本单收款地址。
3. 朋友从自己的钱包向该地址**一次性**转入订单显示的应入金额（BEP20 USDT，BNB Chain）。核对网络：转到其他链或其他代币无法自动找回。
4. 入金最终确认后，卖家声明交付，买家验收；你在后台审核出款。
5. 签名页面（主网模式）：如提示订单地址缺 BNB，先“补充出款手续费”；然后准备出款计划 → 本机签名 → 输入 MAINNET 广播 → 刷新回执直到完成。
6. 完成后可在第6部分归集平台手续费。每一步核对后台账本。

任何一步结果与预期不同：**停止操作**，保留页面和截图，不要重新签名或重复转账。

## 当前边界

- 主网流程使用与测试网相同的代码路径，自动测试覆盖主网链 ID、金额上限、签名网络隔离和确认词；**真实主网流程尚未端到端运行过**，第一笔交易就是首次验证。
- 后台与签名都在你的电脑上运行；电脑关机期间不会处理入金和超时，入金会在开机并启动监听后补扫。
- 没有自动定时备份、监控告警或第三方安全审计。限额请根据实际信任程度谨慎调整。

## 群内交易（推荐方式）

1. **白名单**：在后台“网络配置”的“群内交易白名单”里添加你和对方的 Telegram 数字 ID（私聊机器人发 `/id` 可查）。买卖双方都必须在名单内。
2. **建群**：手动建一个 Telegram 群，拉入对方和机器人，**把机器人设为群管理员**（自动建群需要额外的服务账号，尚未实现）。
3. **设角色**：买家发 `/buyer 钱包地址`，卖家发 `/seller 钱包地址`（BEP20，0x 开头）；也可以直接把地址发到群里，再点“我是买家/我是卖家”（只有发地址的人能点）。
4. **定条款**：任一方发 `/terms 金额 交易内容`，例如 `/terms 10 账号一个，1小时内交付`。卡片显示手续费和买家应付金额；双方各点一次“确认交易”。任何一方修改角色或条款都会清除确认。
5. **入金**：双方确认后自动生成订单并绑定本群；入金监听运行时自动分配本单收款地址并在群里显示。买家一次性转入应付金额，最终确认后群里通知。
6. **交付与放款**：卖家点“卖家 · 已交付”；买家点“买家 · 放款给卖家”并再次确认。之后进入后台审核与本机签名，链上确认后完成并在群里通知。
7. **退款与争议**：任一方可点“申请退款”，由另一方同意或拒绝（拒绝即转争议）；“发起争议”或 `/dispute 理由` 冻结出款，由管理员在后台裁决。争议附件请在私聊提交。
8. **查询**：`/menu` 订单卡和按钮，`/balance` 托管余额，`/blockchain` BscScan 交易链接，`/reset` 在生成订单前取消草稿。

- 每个按钮都会核对点击者是否为对应角色本人以及订单当前版本；旧按钮、别的订单的按钮无效。
- 一个群同时只能有一笔进行中的订单；订单完成或关闭后可以在同一群开始下一笔。
- 单笔与托管总额上限、手续费、超时规则与后台创建的订单相同。

### 一键建群与开放交易（更新）

- **一键建群**：私聊机器人首页点“⚡ 创建担保群”，Telegram 会让你选择或新建一个群，并直接以管理员身份拉入机器人（请保留默认勾选的权限）。机器人进群后发出交易说明和一个**需审批的邀请链接**（24小时有效）；把链接发给对方，对方申请入群后机器人自动审核。
- **入群审核规则**：申请人必须当前允许交易（开放交易，或在白名单中）；本单买家/卖家随时放行；其他人只在群里不超过两人（你和机器人）时放行一位，避免陌生人混入。
- **开放交易**：后台“网络配置” → “群内交易开放设置”。打开后任何人都能通过机器人建单；关闭时回到只限白名单。可设置每人同时进行中的订单上限（默认2，1至20）。
- 开放前请确认：单笔与托管总额上限是否合适（`.env.mainnet`）、后台是否能持续在线、你是否有时间处理争议。放款仍需你审核并本机签名。
- **群语言**：群卡片上的“中文 / English”按钮，或在群里发送 `/language en` / `/language zh`。本单买家、卖家或群管理员可切换；从机器人进群起即可设置，生成订单后沿用，不影响个人私聊语言。

## 管理员提醒、自动恢复与补款

- **管理员 Telegram 提醒**：后台“网络配置” → “管理员 Telegram 提醒”，添加你的 Telegram 数字 ID（该账号须先私聊机器人 `/start`），点“发送测试提醒”确认收到。之后申请放款、同意退款、新争议及补充说明、异常入金、入金未补足、订单超时、链上确认冲突、出款完成、群内新订单、入金（含部分入金）都会私聊提醒；入金监听出错每小时最多提醒一次，手续费钱包低于 0.0005 BNB 每天提醒一次。机器人未运行时提醒会在启动后补发（只补最近两天）。
- **重启后自动恢复**：后台记住你最后一次手动开启/停止入金监听和机器人的状态，重启后自动恢复（失败会重试几次，仍失败时在后台显示错误并触发提醒）。手动停止后不会自动恢复。
- **开机自启动**：双击 `设置开机自启动.cmd`，之后登录 Windows 时自动在后台启动主网后台（不打开浏览器，日志在 `data/production-mainnet-service/autostart.log`）。双击 `取消开机自启动.cmd` 撤销。电脑需要保持开机、不睡眠。
- **少付补款**：买家少付时，订单显示“已到账 X，还差 Y”，补足到同一地址即可；多笔累计正好等于应付金额时自动变为已入金。累计超出应付金额的那一笔转人工且不计入托管；截止时仍未补足的订单资金保留并转人工。

## 人工待处理订单

多付、关单后才到账、到期未补足、出款审核被拒、链上确认冲突等情况会让订单进入“人工待处理”，并发送管理员提醒。后台打开该订单详情，底部“人工处理”显示托管余额、异常款及合计，可选择：

| 处理方式 | 适用 | 结果 | 确认词 |
| --- | --- | --- | --- |
| 确认入金并继续交易 | 托管 + 异常款合计正好等于应入金额（如到期后补齐） | 异常款并入托管，订单回到“已入金” | CONTINUE |
| 全部退回买家 | 地址内有款项 | 生成“人工全额退回”出款申请（收款方为买家确认过的地址），仍需在“出款审核”通过、签名页签名并输入 MAINNET 广播；链上确认后订单为“已退款” | REFUND |
| 关闭订单 | 地址内没有款项 | 订单关闭 | CLOSE |

- 每次处理都要填写说明，记录不可修改，并留在订单详情的“处理记录”中。
- 如果该订单还有已签名但未确认的出款交易，必须先在签名页刷新核对原交易，之后才能人工处理，避免重复付款。

## 参照 CoinXpert 的界面与命令（英文优先）

- **私聊**：欢迎卡片（品牌名、手续费分档、真实成交与争议统计、如何声明身份），按钮 WHAT IS ESCROW / INSTRUCTIONS / TERMS / CREATE ESCROW GROUP（配置客服后另有 CONTACT）。命令：`/start`、`/create`、`/instructions`、`/rules`、`/whatisescrow`、`/menu`、`/guide`、`/orders`、`/id`、`/language`。
- **群内**：`/seller 地址`、`/buyer 地址`（或直接贴地址选角色）、`/terms 金额 内容`、`/description 内容`、`/menu`（快捷九宫格：使用说明、联系客服、放款给卖家、退款给买家、重置角色、余额、区块链接、收款二维码、争议，以及交易卡片）、`/deal`、`/pay_seller`、`/refund_buyer`、`/balance`、`/blockchain`、`/qr`、`/verify 地址`、`/convert 数量 币种 币种`、`/dispute 理由`、`/reset`、`/language`、`/guide`。
- **与参考机器人有意不同之处**：先定条款、双方确认后再入金；只支持 BEP20 USDT；成交统计为数据库真实数字；不使用对方名称、Logo 与评价。
- **卖家直接退款**：卖家点「退款给买家」并确认后，直接生成全额退款（无需买家同意）。买家点该按钮则发起退款申请，需卖家同意。
- **卖家超时未交付自动退款**：订单入金后在“已入金待交付”阶段的时限（默认 1440 分钟 = 24 小时，可在后台“订单超时与提醒”修改）内卖家未点「已交付」，系统自动生成全额退款给买家。当前仍为人工审核出款，自动退款同样进入“出款审核”，并发送管理员提醒。
- **配置**：`.env.mainnet` 中 `PRODUCTION_BOT_BRAND`（欢迎卡片显示的名称）、`PRODUCTION_SUPPORT_USERNAME`（客服/仲裁员 Telegram 用户名）、`PRODUCTION_DEFAULT_LANGUAGE`（默认语言）；上限设为 `none` 即关闭。

## 自动出款

后台「网络配置」页最上方「🤖 自动出款」（仅负责人）。默认关闭。

1. 选择平台钱包加密备份文件（部署签名页生成的那份 JSON），输入备份密码，点「解锁钱包」。后台会核对备份是否属于本实例已配置的公开分支和网络，不符合则拒绝。
2. 点「开启自动出款」，输入 `AUTO`。

开启后每 15 秒检查一次：自动审核待审核出款（买家放款、协商/卖家/超时退款、仲裁结果、人工退款）→ 缺手续费时先从手续费钱包补 → 用对应子地址签名 → 广播。广播后 10 分钟未确认会自动加速；已完成订单的手续费自动归集到收益钱包。每笔广播都会发 Telegram 提醒并写入审计。

- 私钥只在内存中，**每次重启后台都要重新解锁**；未解锁时会提醒，出款排队等待。
- 入金监听未运行时暂停。
- 连续 5 轮出现真实错误会自动关闭，记录原因并发提醒；“等待确认”“等手续费到账”这类情况不算错误。
- 不设单笔或每日上限（按要求）。最大的风险是后台电脑被入侵：解锁期间，入侵者可以借助本进程转出资金。请保持电脑安全，不用时可点「锁定钱包」。

账号管理：负责人可添加「仲裁员」（只能查看和裁决争议）和「审核员」账号，也可停用账号；所有人都可修改自己的密码。
