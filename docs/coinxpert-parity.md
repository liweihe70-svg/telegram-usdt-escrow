# CoinXpert 交互对照表

依据：`docs/COINXPERT-INTERACTION-HANDOFF-FOR-CLAUDE.md`、`docs/coinxpert-observations.md`、`data/research/2026-10-12/` 下两份文字记录与截图（含无关聊天和个人信息，仅本地查看，不得发布或作为素材）。

证据等级：**A** 实际观察；**B** 仅在示例图/宣传/历史消息中出现；**C** 无证据；**D** 本项目独立设计。

状态：**对齐** 已按原版可见形式实现；**保留差异** 刻意不同（原因见备注）；**近似** 技术或素材限制下尽量接近；**自设** 无原版证据，按本项目设计，不代表原版行为。
