# 测试网签名与出款

仅支持BNB测试网97的已审核商品订单RELEASE。主网、退款、仲裁、gas自动补给与手续费归集未开放。这个页面是独立端口的本机浏览器签名器，不是经过审计的生产冷签名服务。

## 使用前提

- 在同一个浏览器打开127.0.0.1:8782和127.0.0.1:8783，先在8782以OWNER登录。Codex内置浏览器与Edge不共享登录会话，使用哪个浏览器签名，就在哪个浏览器先登录后台。
- 8782必须加载005出款迁移的新服务，并启动测试网入金监听；机器人如需要也须单独启动。
- 商品订单已由真实双方确认、独立地址收到完整测试代币、卖家声明交付、买家验收申请，并由管理员审核通过。只有一个Telegram账号时无法制造这份真实批准订单，最后仍需双账号联调。
- 平台加密钱包备份和密码已完成恢复验证。主服务只有公开xpub，无法代替你签名。
- 出款源地址是该订单的独立子地址，不是部署代币的MetaMask地址。这个子地址本身必须持有足够tBNB支付gas；需要你用测试钱包向它补充测试手续费，当前无自动补给。准备交易会报告余额不足，不会自行转入gas。

## 本机流程

1. 打开 http://127.0.0.1:8783/#payout-panel ，第5部分“已审核的测试网出款”。点击“连接已登录后台”。它读取OWNER会话并取得CSRF；后台页面执行保存等操作前可能需要刷新会话。
2. 选择已审核申请，核对订单、链97、测试合约、独立源地址、卖家收款地址、本金和保留手续费。
3. 点击“准备不可变交易计划”。后台再次核对审批快照、订单版本、复式账本、公开分支与节点，要求源地址测试代币余额精确等于应入金额，核对tBNB和nonce，保存不可变计划。再次点击返回同一计划，不重新分配nonce。
4. 核对nonce、gas limit、gas price与最大费用。gas含20%估算余量，单笔gas limit最多200000、gas price最多5gwei，总手续费上限0.01tBNB。初版固定legacy交易，暂不提供加价替换。
5. 选择平台加密JSON备份，在本页输入备份密码和TESTNET，点击“本机签名并提交核验”。页面本机解密、核对根和子地址并签名；不上传文件、密码、助记词或私钥。上传的是可以公开广播的已签名交易。后台核对链、签名人、nonce、合约、calldata、金额0、gas及审批后存为SIGNED，尚不广播。
6. 再核对一次，输入TESTNET，点击“广播原签名测试交易”。这是实际的测试网转账，消耗源地址tBNB，向卖家发送本单本金。后台广播已保存的原字节串，不临时生成新签名。一次结果不明时仅查询或重发这个原交易哈希。
7. 后台每10秒查最终确认回执，重启后继续查询SIGNED/BROADCAST记录，不自动发起广播。确认成功且Transfer事件的代币、来源、卖家地址和金额正确后，订单COMPLETED、申请PAID，并落入唯一且平衡的出款账本。刷新页面查看结果。

本金出款后，手续费仍在独立子地址。正常完成时账本将其记作平台收入；没有物理归集。BNB gas支出暂未进入独立原生币账本，只是预检限额，不能将本模块视为完整多资产对账。

## 异常与恢复

- 签名与广播明确分开，没有自动解密或自动批量付款。主服务永不读取钱包私钥。
- 已保存签名及交易哈希后不能覆盖或删除，也不允许改收款地址/金额/nonce。浏览器刷新可从后台取得同一记录，不需要重签。
- 广播请求超时或数据库确认状态保存失败时，SIGNED记录仍保留；先“刷新出款与回执”。如节点已看到该哈希，重试广播不再次发送；如果尚未看到，只有nonce仍一致且预检通过时才发送相同原字节串。交易哈希相同，不能变成第二份不同付款。
- 未审核、订单版本/账本变化、停止入金监听、少币、多币、缺gas、nonce变化、手续费上涨超过原计划等均阻止新广播。
- 链上回退交易确认后，标REVERTED并转人工，测试代币账本不扣款。gas可能已消耗。此版本无解除暂停或重建计划入口，需后续安全恢复流程，不能删除记录重试。
- 广播后出现额外入金，订单可能已冻结。若原出款最终成功，仍记入实际出款账本，维持人工待处理并保留手续费责任，不因冻结而漏记已经发生的付款。
- 未最终确认、回执冲突、错误Transfer或RPC不通都不记“已完成”。RPC错误会保存通用提示，保留原交易供核查。

## 当前验证边界

新增后台测试使用独立PGlite、公开合成HD种子、受控RPC，覆盖审批/角色/快照、错误签名、不可变nonce和签名、超时恢复、最终确认唯一记账、错金额/错回执拒绝、链上失败和广播后订单冻结。助手测试还验证本机解密后导出的子地址签名，未读取用户备份。

## 补充出款手续费（tBNB）

每单独立收款地址只收到测试代币，没有 tBNB 就无法支付出款 gas。平台用同一钱包的保留子地址（序号 2147483647，订单地址永不分配到此序号）作为手续费钱包，由它向订单地址补充 tBNB。

1. 连接后台后，签名页面第5部分的“补充出款手续费”会显示手续费钱包地址和余额。首次使用前，从 MetaMask 向该地址转入少量测试 BNB（例如 0.05 tBNB，可从 BNB 测试网水龙头领取）。
2. 选择已审核且尚未准备出款计划的申请，点击“准备手续费补充计划”。补充金额为当前出款估算 gas 的两倍减去订单地址已有 tBNB；已有足够 tBNB 时会提示可直接准备出款。
3. 使用上面选择的同一份加密备份和密码，输入 TESTNET 本机签名；后台核验发送方、接收方、金额、nonce 与 gas 后保存，不广播。
4. 再次输入 TESTNET 广播。点击“刷新出款与回执”，等待最终确认并记账后，再“准备不可变交易计划”进行出款。

- 未签名的补充计划在手续费钱包 nonce 变化后自动作废并重建；已签名的计划不会被替换，只能广播原交易或等待其确认。
- 同一时间只允许一笔已签名、未确认的补充交易，避免手续费钱包 nonce 冲突。
- 账本使用独立的 wei 科目：`gas:97:station`（手续费钱包净流出）、`gas:97:order:<订单>`（订单地址可用 gas）、`expense:gas:97`（已消耗 gas）。出款最终确认时按实际 gasUsed 从订单科目转入费用；链上回退的补充交易只记手续费。手续费钱包的外部充值不入账，所以 `gas:97:station` 为负数表示累计净支出，实际余额以链上为准。

## 归集平台手续费

正常放款或“本金给卖家”的裁决最终确认后，订单地址仍留有平台手续费（默认5 USDT 等值测试代币）。签名页面第6部分把它转到平台收入地址：同一钱包的保留子地址（序号 2147483646），订单地址永不分配到此序号，所以无需另行配置收款地址，也无法被改配置转走。

1. 在第5部分连接已登录后台后，第6部分会列出可归集的订单，并显示平台收入地址与账面已归集金额。
2. 选择订单，点击“准备不可变归集计划”。订单地址的代币余额必须正好等于应收手续费，多或少都会拒绝并转人工核对；还需要足够的 tBNB 支付 gas。补充出款手续费时按两倍估算补给，通常出款后剩余的 tBNB 足够归集；不够时可从 MetaMask 直接向订单地址转少量测试 BNB。
3. 选择加密备份、输入密码和 TESTNET，本机签名；签名页面会再次核对接收方确实是本钱包的平台收入子地址。
4. 输入 TESTNET 广播，点击“刷新可归集订单与回执”等待最终确认。

- 冻结或转人工的订单、退款、全部退买家的裁决不会出现在列表中。
- 账本：最终确认后代币从 `asset:97:<代币>`（各订单地址持有）转入 `treasury:97:<代币>`（平台收入地址持有），gas 记入 `expense:gas:97`。链上回退只记 gas，之后可用新 nonce 重新准备。
- 每单最多一笔已确认归集；未签名计划在订单地址 nonce 变化时作废重建，已签名计划只能广播原交易。

## 出款长时间未确认：加速

已广播的出款如果因 gas 价格偏低迟迟不确认，可在签名页面第5部分的“提高手续费加速”区域重新定价。

1. 选择该出款，点击“准备加速计划”。新计划与原交易使用同一 nonce、同一收款方、金额和数据，只把 gas 价格提高到“上次价格×1.125”与节点当前价格中较高者（节点通常要求替换交易至少高10%）。
2. 使用同一份加密备份和密码，输入 TESTNET 本机签名。签名页面会核对除 gas 价格外与原计划完全一致、且价格确实提高。
3. 输入 TESTNET 广播加速交易，然后“刷新出款与回执”。

- 原交易与所有加速交易共用一个 nonce，链上最多只成交一笔，不会重复付款。后台核验回执时会依次检查原交易和各次加速，哪一笔最终确认就按哪一笔记账，其余标记为 SUPERSEDED（已被替代）；原交易哈希保持不变，实际成交的哈希记在 `confirmed_tx_hash`。
- 以下情况拒绝加速：该 nonce 已上链（请刷新回执）、订单已冻结或审批已变化、订单地址 tBNB 不足以支付更高手续费（可从 MetaMask 直接向订单地址转少量测试 BNB）、超过测试网手续费上限、已加速5次。
- 未签名的加速计划在节点价格上涨后作废并按新价格重建；已签名未广播的计划只能广播原字节。
